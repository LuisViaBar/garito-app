Todo converge en miembros

Doce de las trece tablas apuntan a miembros, casi siempre para dejar constancia de quién hizo algo. Es la tabla de la que depende el esquema entero: si se corrompe, se corrompe todo. Por eso es la primera que se construye y la que primero recibe políticas de acceso.

Las veinticuatro claves foráneas

Cada fila es una dependencia real que la base de datos verifica. La columna de borrado dice qué pasa con el hijo cuando desaparece el padre: donde no hay cascada, la base de datos impide borrar el padre mientras existan hijos, que es lo que queremos para todo lo que toca dinero.

Lo que no es una tabla

Tres vistas. Una vista es una consulta guardada que se comporta como una tabla pero no almacena nada: se recalcula al consultarla. Es como se evita que un saldo guardado se desincronice de los hechos que lo producen.

VistaSale deQué devuelve
v_saldo_miembroapuntesSaldo de cada miembro, meses adeudados o adelantados, y los euros sueltos que sobran de la división
v_extracto_miembroapuntesApuntes en orden con saldo acumulado, como un extracto bancario
v_stock_bajoproductosProductos cuya cantidad está por debajo del umbral

Aviso sobre el saldo. El cálculo suma todos los apuntes, incluidos los que tienen anulado = true. Filtrarlos dejaría el contraapunte sin su original y el miembro aparecería con dinero a favor que nunca pagó. El flag existe para los índices de unicidad y para atenuar esas líneas en pantalla, nunca para filtrar sumas.
